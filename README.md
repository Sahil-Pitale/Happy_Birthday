# 🎂 Happy Birthday Piaa ✨

A cute and interactive **Happy Birthday surprise website** created especially for **Piaa** 💖

This project takes the user through a fun and memorable birthday journey filled with balloons, surprises, memories, a heartfelt letter, and a final celebration! 🎉

## ✨ Features

🎈 **Balloon Pop Game**
Pop the balloons to reveal a special message.

🎂 **Make a Wish**
Tap the candle flame to make a birthday wish.

📸 **Sweet Memories**
View and interact with special photo memories.

💌 **Message From Heart**
A heartfelt birthday letter appears with a character-by-character typing animation.

✏️ **Animated Pen Effect**
A floating pen follows the text while the letter is being written.

🎁 **Final Surprise**
Tap the gift box to unlock the final birthday surprise.

🎉 **Confetti Celebration**
Celebrate with beautiful confetti animations.

💕 **Cute Animated Background**
Floating hearts, flowers, sparkles, and other animated elements create a lovely experience.

📱 **Responsive Design**
The website is designed to work on desktop and mobile devices.
